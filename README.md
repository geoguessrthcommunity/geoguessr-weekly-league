## 🧮 กฎการคำนวณคะแนน (Phantom Score 10%)
1. **6 Rounds ย่อยต่อแมพ:** ในแต่ละ Map จะมี 5 Rounds ปกติ (เต็มรอบละ 5,000) และผลรวม 5 รอบ (เต็ม 25,000) นับเป็น Round ทิพย์ที่ 6
2. **สูตร Phantom Score:**
   $$\text{Phantom Score} = \text{Raw} + 10\% \times (\text{Max} - \text{Raw})$$
3. **คะแนนในแต่ละ Round (Head-to-Head Half-Tie):** นำคะแนนไปเปรียบเทียบตัวต่อตัวกับคู่แข่งทุกคนในรอบนั้น (ไม่นับตัวเอง):
   - ชนะขาด (Raw เรา > Phantom คู่แข่ง) = **1 แต้ม**
   - เสมอ (ทั้งสองคนอยู่ในระยะ Phantom ของกันและกัน) = **0.5 แต้ม**
   - แพ้ = **0 แต้ม**
4. **คะแนนประจำ Map (Points):** รวมแต้ม 6 Rounds เข้าด้วยกันเป็น `ptsRounds` แล้วนำไปจัดอันดับเทียบกับผู้เล่นทุกคนอีกครั้ง เพื่อแปลงเป็น Points ประจำ Map (คนได้ที่ 1 ของแมพจะได้คะแนนเต็มเท่ากับจำนวนผู้เล่น เช่น 555 แต้ม)
5. **Total Points:** รวม Points จากทั้ง 7 Maps เพื่อจัดอันดับสุดท้ายประจำสัปดาห์ (มีเหรียญ 🥇 🥈 🥉 ให้ผู้เล่นหัวตาราง)

## 🚀 ขั้นตอนการติดตั้งและเริ่มต้นใช้งาน

### ขั้นตอนที่ 1: ติดตั้งฐานข้อมูลบน Supabase (ฟรี)
1. ไปที่ [Supabase.com](https://supabase.com/) แล้วสร้างโปรเจกต์ใหม่
2. ไปที่เมนู **SQL Editor** ด้านซ้าย -> กด **New query**
3. ก๊อปปี้เนื้อหาในไฟล์ `supabase_schema.sql` ทั้งหมดไปวาง แล้วกดปุ่ม **Run**
4. ไปที่เมนู **Project Settings** -> **API** เพื่อคัดลอกค่า 3 ตัวนี้เก็บไว้:
   * **Project URL**
   * **anon / public key**
   * **service_role key** (เก็บเป็นความลับ)

### ขั้นตอนที่ 2: ตั้งค่าหน้าบ้าน (Frontend)
1. เปิดไฟล์ `config.js`
2. ใส่ `SUPABASE_URL` และ `SUPABASE_ANON_KEY` ที่ได้จากขั้นตอนที่ 1

### ขั้นตอนที่ 3: เปิดใช้งานหน้าเว็บ
* **วิธี Drag & Drop (ง่ายสุด):** เข้าเว็บ [Netlify Drop](https://app.netlify.com/drop) แล้วลากโฟลเดอร์นี้ทั้งโฟลเดอร์ไปวาง จะได้ลิงก์เว็บไซต์พร้อมใช้งานทันที!
* **หรือเชื่อมกับ GitHub:** Push ขึ้น GitHub แล้วเชื่อมต่อกับ Netlify

### ขั้นตอนที่ 4: การรันดึงคะแนนอัตโนมัติ (Auto-Sync ทุก 30 นาที)
* **ทางเลือก A (รันบน GitHub Actions 24 ชม. แม้ปิดคอม):**
  1. Push โค้ดขึ้น GitHub
  2. ไปที่ Settings -> Secrets and variables -> Actions
  3. ใส่ Secrets: `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `GEOGUESSR_COOKIE` (คุกกี้ `_ncfa` จากบอท)
* **ทางเลือก B (รันบนคอมตัวเอง ไม่ต้องใช้ GitHub):**
  1. สร้างไฟล์ `.env` แล้วใส่ `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `GEOGUESSR_COOKIE`
  2. ดับเบิ้ลคลิกไฟล์ `start-sync.bat` บนเครื่อง มันจะวนลูปดึงคะแนนให้ทุก 30 นาทีอัตโนมัติ

## ⚙️ การใช้งานแอดมิน (admin.html)
1. เข้าไปที่หน้า `admin.html`
2. กรอก `SUPABASE_SERVICE_ROLE_KEY` แล้วกดบันทึก
3. กรอกชื่อสัปดาห์, ข้อความหัวเว็บ, วันตัดรอบ (ถ้ามี)
4. กรอกข้อมูล **7 Maps** (สามารถพิมพ์ข้อความยาวได้ เช่น `Map 1 : Europe | NM - 1'` และวางลิงก์ Challenge)
5. กดยืนยันเพื่อเปิดสัปดาห์ใหม่ได้ทันที
